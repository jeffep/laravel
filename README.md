## 🧐 About <a name = "about"></a>

I have become unhappy with the pace at which HomeAssistant is progressing.
And some of the ability a user has to configure it.  Therefore, I am attempting
to change and use a linux server running on an old computer.  This should run
faster than the ARM equipped Home Assitant green that is for sale.  Also, I believe
this should allow a more easily configured system using all the tools available:
HTML, javascript, PHP, SQLite3, bash scripts, and others, including C functions
if needed.  While this will all be configured from scratch, it will not be too
difficult.

## 🏁 Getting Started <a name = "getting_started"></a>

What you can do (what I did) is download and install Laravel Herd for free
and load it on a development machine, and also onto the server.  Laravel Herd
allows you to quickly set up a safe login and working environment.  It is a
little difficult to get used to, but it is a nice fully configured environment
provided to get started quickly.  Much better than starting from scratch on
login, DB connection, etc.
 See [deployment](#deployment) for notes on how to deploy the project on a live system.
